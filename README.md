# Customer Analytics Dashboard

An interactive data analytics and machine learning project built using Python and Streamlit to analyze retail sales, segment customers, and predict repeat purchase behavior.

## Project Overview

This project uses the **UCI Online Retail Dataset** to explore historical retail transactions and extract meaningful business insights. It combines data cleaning, exploratory data analysis (EDA), customer segmentation, and machine learning into an interactive dashboard.

The dashboard helps users understand sales trends, identify customer groups, and estimate the likelihood of customers making another purchase within the next 30 days.

## Objectives

- Analyze retail sales and revenue trends.
- Identify top-selling products and high-performing countries.
- Segment customers using Recency, Frequency, and Monetary (RFM) analysis.
- Build machine learning models to predict repeat purchase behavior.
- Present analytical results through an interactive dashboard.
- Generate business recommendations based on customer and sales patterns.

## Dataset

**Source:** UCI Machine Learning Repository — Online Retail Dataset

The dataset contains transaction records from a UK-based online retailer between December 2010 and December 2011.

It includes information such as:
- Invoice number
- Product code and description
- Quantity purchased
- Invoice date
- Unit price
- Customer ID
- Country

The original dataset contains **541,909 transaction records and 8 columns**.

Dataset source: [UCI Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)

## Data Cleaning and Preprocessing

The following data preparation steps were performed:

- Converted invoice dates into datetime format.
- Removed duplicate records during the cleaning workflow.
- Excluded transactions without a Customer ID for customer-level analysis.
- Excluded cancellation invoices.
- Filtered out transactions with non-positive quantities or unit prices.
- Created a `Revenue` feature using:

  `Revenue = Quantity × UnitPrice`

After purchase filtering, the analysis dataframe contained approximately **397,884 transaction records and 4,338 unique customers**.

## Customer Segmentation

Customer segmentation uses RFM analysis:

- **Recency:** Number of days since the customer's last purchase.
- **Frequency:** Number of distinct orders placed by the customer.
- **Monetary:** Total revenue generated by the customer.

K-Means clustering is used to group customers with similar purchasing behavior.

The segments can help identify low-activity customers, regular customers, and high-value customers.

## Machine Learning Models

Two classification models were developed to estimate repeat purchase behavior.

| Model | Accuracy | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|
| Logistic Regression | 75.73% | 70.66% | 28.65% | 40.77% |
| Random Forest | 72.72% | 55.42% | 32.78% | 41.20% |

The models use the following features:

- Recency
- Frequency
- Monetary

The prediction task estimates whether a customer will make another purchase within the following 30 days.

**Note:** These results come from a chronological historical test split. Model performance may vary on other data, and predictions are estimates rather than guarantees.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.10 or a compatible version
- pip
- Git (optional)

### 1. Clone the repository

```bash
git clone https://github.com/vijay-negi07/customer-analytics-dashboard.git
```
### 2. Open the project directory

```bash
cd customer-analytics-dashboard
```

### 3. Run the dashboard

```bash
python -m streamlit run app.py
```

Streamlit will provide a local URL, usually `http://localhost:8501`, where the dashboard can be viewed in a browser.
